# _containers — 컨테이너 (작성 예정)

> 공식 concepts의 Containers에 대응합니다.

이 폴더는 아직 문서가 없는 stub입니다. 공식 concepts의 Containers 대분류(이미지, Container Environment, Runtime Class, Container Lifecycle Hooks, CRI)를 다룰 자리로 미리 열어 두었습니다.

컨테이너 격리 원리(cgroups·namespace·UnionFS) 자체는 `02_os` 계열의 정독 노트가 다루므로, 여기서는 *Kubernetes가 컨테이너를 어떻게 다루는가*(이미지 pull 정책, lifecycle hook, RuntimeClass)에 초점을 둘 예정입니다. 문서가 5편 이상 쌓이면 정식 번호 폴더로 승격합니다.
