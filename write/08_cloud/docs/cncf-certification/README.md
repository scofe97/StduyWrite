# 08_cloud/docs/cncf-certification — CNCF 자격증 대비와 실무 개념

---

> CNCF(Cloud Native Computing Foundation)와 Linux Foundation의 자격증 커리큘럼을 1차 자료로 삼아 시험 대비 전략과 실무 핵심 개념을 정리하는 자리입니다. CKA(Certified Kubernetes Administrator)를 첫 편으로 두고, 이후 자격증 주제를 확장합니다.



## 1차 자료

> 노트 프론트매터 `source` 에 적힌 주소입니다.

- CNCF Curriculum 저장소: <https://github.com/cncf/curriculum>
- Linux Foundation CKA 시험 안내: <https://training.linuxfoundation.org/certification/certified-kubernetes-administrator-cka/>
