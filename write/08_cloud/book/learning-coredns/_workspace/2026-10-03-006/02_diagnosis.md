   → 처방: 연결어미 직후 쉼표는 지운다. 절 셋 이상이 이어진 문장은 연결어미 자리에서 끊는다. 새로 생긴 문장은 150자 이하로 둔다.
2. **E-2** 동일 종결 동사 반복 (보도 동사 "적습니다") — "저자들이 (직접/그대로/분명히) 적습니다", "문서가 적습니다", "못 박습니다", "덧붙입니다", "짚습니다"가 절마다 문장 끝에 온다. 어휘 다양성이 낮게 나온 주원인이다. · 근거: lexical_diversity 0.41 (z=-4.80). 예: "저자들이 직접 적습니다. 보안상의 이유로 …" / "저자들이 이유를 적습니다." / "저자들이 그대로 적습니다."
   → 처방: "저자들이 ~ 적습니다." 단독 도입 단문은 뒤 문장과 합쳐 인용 주체를 안에 넣는다("저자들에 따르면 …", "… 고 저자들은 본다"). 같은 동사가 이웃 문장에서 거듭 나오지 않게 동사를 바꾼다. 출처 귀속(저자/문서/노트)은 바꾸지 않는다.
3. **D-3** 도식·표 앞 열거 도입 공식 — 그림과 표마다 "~을 나란히 놓으면 이렇습니다 / 맞춰 보면 이렇습니다 / 이으면 아래와 같습니다 / 펼치면 이렇습니다"로 들어간다. · 근거: 2·3·5·6·7·9절 그림 도입문 8회 안팎. 예: "세 설정에 … 응답의 두 섹션을 나란히 놓으면 이렇습니다."
   → 처방: 같은 틀이 연달아 나오는 곳만 바꾼다. 그림이 보여 주는 내용을 서술문으로 바로 적고 "이렇습니다" 꼬리를 뗀다. 그림 줄과 그 바로 뒤 설명 문장(주황 칸·행이 무엇을 뜻하는지)은 그대로 둔다.
4. **I-2** "자리" 형식명사 강조 — "눈여겨볼 자리가 하나 있습니다", "가장 조심할 자리입니다", "가장 자유로운 자리", "노리는 자리", "걸리는 자리가 둘입니다"처럼 "자리"가 "주목할 점은" 구실을 한다. · 근거: 1·5·6·9절과 적용 관점에서 반복. 예: "여기서 눈여겨볼 자리가 하나 있습니다."
   → 처방: 예고만 하는 단문("~할 자리가 있습니다")은 뒤 문장에 흡수해 바로 내용으로 들어간다. 물리적 위치를 가리키는 "자리"(헤딩 문구, "막는 자리가 운영체제 위쪽")는 남긴다.
5. **A-18** 관형절 3중 이상 좌향 수식 — 특히 "원서가 기준으로 삼은 v1.5.0 의 README/코드"가 고정구처럼 되풀이되고, 명사 앞에 긴 수식이 쌓인 문장이 많다. · 근거: relative_clause_nesting 14. 예: "CoreDNS 조직 안에 있지만 저장소에 들어 있지도 기본 컴파일되지도 않는 외부 플러그인이고"
   → 처방: 수식절을 앞 문장의 서술부로 풀거나 명사 뒤로 돌린다. 버전·고유명사·인라인 코드는 한 글자도 바꾸지 않는다.
