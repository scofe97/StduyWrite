## 규칙

> 외부 AI 도구가 정리한 요약. 파일 이름은 `YYYY-MM-DD_주제.md` 입니다.

- 머리 한 줄: 출처 · 날짜 · 분야 · 미검증.
- mkdocs 가 `_` 로 시작하는 폴더를 빼므로 Pages 에는 올라가지 않습니다.
- 2026-11-14 이전 요약 12편은 옛 형식(`## 핵심 키워드`·`## 요점`·`## 경고`)이고, 새 형식은 writing-method 스킬의 `task-digest.md` 를 따릅니다.
