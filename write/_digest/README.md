# AI 요약

---

> 목적 2 — 외부 AI 요약.
> 목적 3 — 배울 자료 조사(책·강의·공식 문서 후보 비교)도 이 폴더에 같은 형식으로 둡니다.



## 규칙

> 외부 AI 도구가 정리한 요약. 파일 이름은 `<분야>/YYYY-MM-DD_주제.md` 입니다.

- 머리 한 줄: 출처 · 날짜 · 분야 · 미검증.
- 하위 폴더는 머리 줄 `분야:` 의 첫 태그에서 `-keywords` 를 뗀 이름입니다. 여러 분야에 걸친 요약은 첫 태그 폴더에 하나만 둡니다.
- 연재물(플레이북 1~6)은 한 폴더에 모으려고 공통 분야를 첫 태그로 둡니다.
- mkdocs 가 `_` 로 시작하는 폴더를 빼므로 Pages 에는 올라가지 않습니다.
- 2026-11-14 이전 요약 12편은 머리 줄 위에 제목 줄이 있는 옛 모양이고, 형식은 writing-method 스킬의 `task-digest.md` 를 따릅니다.
