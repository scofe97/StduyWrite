## AI 요약 (`_digest/`)

> 외부 AI 도구가 정리한 요약. 파일 이름은 `YYYY-MM-DD_주제.md` 입니다.

- 머리 한 줄: 출처 · 날짜 · 분야 · 미검증.
- mkdocs 가 `_` 로 시작하는 폴더를 빼므로 Pages 에는 올라가지 않습니다.
