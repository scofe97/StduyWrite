---
> 유튜브 영상의 자막을 근거로 만든 요약 노트를 모읍니다. 영상 내용을 옮기는 데서 그치지 않고, 이미 `write/`에 쌓인 노트와 대조해 무엇이 새로운지까지 적는 것을 수록 조건으로 둡니다.

## 수록 기준

요약만으로는 이 폴더에 들어오지 않습니다. 영상이 주장하는 학습 경로나 기술 설명을 기존 노트와 나란히 놓고, 이미 다룬 것과 실제로 비어 있는 것을 갈라 적어야 합니다. 그 대조가 없으면 영상은 그냥 다시 보면 되는 자료이고 노트로 남길 이유가 없습니다.

출처는 영상 URL을 클릭 가능한 링크로 남깁니다. 채널명은 추측하지 않고 확인한 값만 적습니다.

번호 체계는 채널 단위로 장을 배정합니다. 같은 채널의 다음 영상은 절 번호를 늘리고, 새 채널은 다음 장 번호로 넘어갑니다.
