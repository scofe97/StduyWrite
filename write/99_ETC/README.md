# 99_ETC
---
> 카테고리로 묶기 애매한 1회성 기록과 참고 자료의 대피소입니다.

## 파일명은 `날짜_문서주제.md`

`01-`, `02-` 같은 번호 prefix 를 쓰지 않습니다. 번호는 읽는 순서를 약속하는 표시인데 이 폴더에는 순서가 없습니다. 서로 무관한 기록이 모이는 자리라 번호를 붙이면 지키지 못할 약속이 남고, 중간 문서가 빠질 때마다 자리가 비어 갑니다. 실제로 이 폴더의 01·02·04 는 삭제된 뒤 번호만 비어 있었습니다.

날짜는 그 자료를 남긴 날(`YYYY-MM-DD`)입니다. 조사와 판단의 시점이 이 폴더에서 유일하게 의미 있는 정렬 축입니다. 기술 자료는 시간이 지나면 사실이 바뀌므로, 날짜가 곧 그 문서를 지금 얼마나 믿을지 정하는 근거가 됩니다.

```
2026-09-05_Herdr와 에이전트 터미널 런타임 조사.md
└─ 날짜 ─┘ └───────── 문서 주제 ─────────┘
```

이 규칙은 99_ETC 안에서만 적용됩니다. [`_meta/conventions.md`](../_meta/conventions.md) 의 "파일명 날짜 prefix 금지" 는 카테고리 폴더를 향한 조항이고, 여기가 그 예외입니다. 하위 폴더(`security/`, `대본/`)의 문서에도 같이 적용합니다 — 폴더 이름은 그대로 두고 파일명만 바꿉니다.

## 체류 기간

체류는 최대 3개월입니다. 월간 리뷰(`journal/monthly/`)에서 점검합니다. 오래 머문다면 분류가 모호한 게 아니라 쓸모가 애매한 것이므로 그때는 아카이브나 삭제가 맞습니다. 재배치할 때는 상대 링크 보정을 잊지 않습니다.
