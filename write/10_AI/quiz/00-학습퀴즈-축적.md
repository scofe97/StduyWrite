## 오답 노트 (헷갈리기 쉬운 함정)

- **prefix match**: "뒤가 같으면 뒤는 유지" → ❌. 앞이 깨지면 뒤가 우연히 같아도 못 씀 (캐시 키가 누적 바이트).
- **max_tokens ↔ Task Budget 바꿔치기**: max_tokens = "모른다/잘린다", Task Budget = "인지한다/조절한다". 선택지가 서로 뒤바뀐 오답을 조심.
- **사일런트 무효화 예외**: 사용자 질문(맨 뒤)이 바뀌는 건 정상 — 캐시를 안 깬다. 앞부분(system·tools·JSON)을 흔드는 것만 무효화.
- **/rewind vs 서브에이전트**: /rewind는 *이미 한* 실패를 되돌림 / verbose 출력은 *앞으로 생길* 노이즈를 서브에이전트로 격리.

## 오답 노트 (02-04 — 헷갈리기 쉬운 함정)

- **Tools ↔ Resources 바꿔치기**: 동사로 판단 — "만들다/보내다/바꾸다"=Tool, "읽다/보다/가져오다"=Resource. 생성=Tool, 조회=Resource가 뒤바뀐 선택지를 조심.
- **1 Host = 여러 Server**: "하나의 Host는 하나의 Server에만" → ❌. Claude Code 하나가 여러 MCP에 동시 연결.
- **MCP 토큰 ≠ REST 키**: 호스티드 MCP는 OAuth bearer 토큰. Notion `ntn_`(REST용)은 MCP vault엔 안 통함.
- **비밀은 샌드박스 밖**: 자격증명은 요청이 샌드박스를 떠난 뒤 프록시가 주입 → 주입당해도 못 빼냄.
- **도구는 집중**: 많을수록 좋은 게 아니라, 많으면 모델이 혼란 → 집중된 개수.

## 오답 노트 (02-05 — 헷갈리기 쉬운 함정)

- **4기준 = AND**: "하나라도 예면 에이전트" → ❌. 4기준을 **모두** "예"로 통과해야 정당화. 하나라도 아니오면 더 단순한 티어.
- **최소 티어 원칙**: 분류·요약을 관리형 에이전트로 올리는 건 낭비. 필요 최소 티어에 머문다.
- **Agent→Session**: 회원가입(Agent)은 1번, 로그인(Session)은 매번. 매 실행마다 Agent 생성하면 고아 객체 쌓임.
- **완료 = 루브릭**: vibes/"좋은 리포트" → ❌. 독립 채점 가능한 기준으로.
- **자기승인 금지**: 같은 컨텍스트에서 작성+승인 금지. writer/verifier 분리.
- **구조 사실 = AST 먼저**: LLM 추측·grep 텍스트 매칭 → 가짜 매칭. AST/LSP로 확정 후 해석.
