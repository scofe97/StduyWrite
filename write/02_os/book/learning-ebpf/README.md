# Learning eBPF — 정독 인덱스

---

> 이 폴더는 『Learning eBPF』(Liz Rice, O'Reilly)를 장 단위로 정독하며 정리하는 책-종속 학습노트입니다. 11장을 모두 썼습니다(장에 따라 한 편에서 세 편, 모두 20편).

## 이 책을 여기 두는 이유

> 다른 정독본들이 eBPF 를 쓰는 도구와 제품을 다뤘다면, 이 책은 eBPF 프로그램 자체가 어떻게 생기고 커널에 실려 도는지를 맡습니다.

[『Systems Performance』 정독본](../systems-performance/README.md)은 BCC·bpftrace 를 성능 분석 도구로 씁니다. [『Cilium Up and Running』 정독본](../../../08_cloud/book/cilium-up-and-running/README.md)은 eBPF 데이터패스를 쓰는 CNI 를 다루고, [『Networking and Kubernetes』 정독본](../../../08_cloud/book/networking-and-kubernetes/README.md)은 kube-proxy 를 대신하는 기술로서 eBPF 를 소개합니다. 셋 모두 eBPF 를 이미 만들어진 도구로 봅니다.

이 책은 그 아래를 엽니다. 프로그램을 어떻게 쓰고, 맵으로 커널과 사용자 공간이 무엇을 주고받으며, `bpf()` 시스템 콜·verifier·BTF 가 적재와 이식을 어떻게 받치는지가 이 폴더의 몫입니다. 도구 사용법은 저쪽으로 링크하고, 여기에는 그 도구가 기대는 구조만 남깁니다.



## 범위와 읽는 순서

> 1·2장이 eBPF 가 왜 필요한지와 BCC 로 쓴 첫 프로그램을 세우고, 3장부터 프로그램의 구조·시스템 콜·이식성·verifier·부착 유형·네트워킹·보안을 장마다 하나씩 맡습니다.
