# 현대 도구 참조 시트

---

> 《Learning Modern Linux》 부록 B 의 현대 도구 표와 3장 끝에서 저자가 권하는 모던 대체를 모은 조회용 시트입니다.

## 이 문서의 성격

> 정독 노트가 아니라 조회용 시트라서 학습 목표와 면접 질문을 두지 않습니다.



## 1. 현대 도구 열넷

> 부록 B 의 표입니다. 라이선스와 대체 대상은 책이 나온 2022년 기준입니다.

3장에서 저자가 자주 쓰는 명령으로 드는 것은 `cd`·`ls`·`find`·`cat`·`less` 다섯입니다. 매일 수십 번 치니 타건 하나하나가 아깝다는 것이 모던 대체를 소개하는 출발점입니다. 이들 변종은 흔한 작업에 분별 있는 기본값을 주고 이해하기 쉬운 풍부한 출력을 내며 같은 일을 더 적게 쳐서 끝내게 해 줍니다. 목록을 본 뒤 화면을 지울 때 `clear` 를 치고 엔터를 누르는 대신 Ctrl+L 을 누르라는 팁도 같은 생각입니다.

| 도구 | 라이선스 | 기능 | 대체·보완 대상 |
|------|---------|------|---------------|
| `bat` | MIT · Apache 2.0 | 표시·페이징·구문 강조 | `cat` |
| `envsubst` | MIT | 템플릿 기반 환경 변수 | 해당 없음 |
| `exa` | MIT | 뜻이 있는 색 출력, 합리적 기본값 | `ls` |
| `dog` | European Union Public Licence v1.2 | 단순하고 강력한 DNS 조회 | `dig` |
| `fx` | MIT | JSON 처리 도구 | `jq` |
| `fzf` | MIT | 명령줄 퍼지 파인더 | `ls` + `find` + `grep` |
| `gping` | MIT | 다중 대상, 그래프 | `ping` |
| `httpie` | BSD 3-Clause | 단순한 사용자 경험 | `curl`. `curlie` 도 있습니다 |
| `jo` | GPL | JSON 생성 | 해당 없음 |
| `jq` | MIT | 네이티브 JSON 처리기 | `sed` · `awk` |
| `rg` | MIT | 빠르고 합리적인 기본값 | `find` · `grep` |
| `sysz` | The Unlicense | `systemctl` 을 위한 `fzf` 인터페이스 | `systemctl` |
| `tldr` | CC-BY(내용) · MIT(스크립트) | 명령의 사용 예에 집중 | `man` |
| `zoxide` | MIT | 디렉터리를 빠르게 옮겨 다니기 | `cd` |

`exa` 의 저장소 [ogham/exa](https://github.com/ogham/exa) 는 2024년 9월 24일 뒤로 커밋이 없습니다. 포크인 [eza-community/eza](https://github.com/eza-community/eza) 는 2026년 8월에도 커밋이 이어집니다(2026-11-10 확인).

이 중 셋은 본문에도 나옵니다. `jq` 는 8장의 `journalctl -o json`, `sysz` 는 6장의 `systemctl`, `dog` 는 7장의 `dig` 와 이어집니다.

3장은 `exa`·`bat`·`jq` 를 권하는 이유도 적습니다. `exa` 는 Rust 로 쓰였고 Git 지원과 트리 렌더링이 들어 있습니다. `bat` 은 문법 강조와 페이저에 더해 출력되지 않는 문자 표시와 Git 지원을 갖췄습니다. `jq` 는 `sed`·`awk` 를 갈아 끼운다기보다 JSON 전용 도구이고 HTTP API 와 설정 파일에서 자주 만납니다. 저자는 이 도구들에 이해관계가 없고 유용하다고 느껴 권할 뿐이라고 밝힙니다. 기업 환경에 적용한다면 자기가 쓰는 배포판이 검증한 버전을 설치해 쓰는 편이 좋다고 덧붙입니다.

`find` 와 `grep` 조합을 `rg` 하나로 줄이는 예가 이 표의 논지를 잘 보입니다. 저자의 출력입니다.

```bash
find . -type f -name "*.yaml" -exec grep "sample" '{}' \; -print # *.yaml 마다 grep 을 돌려 찾으면 파일 이름을 찍는다
```

```bash
      app: sample
        app: sample
./app.yaml
```

```bash
rg -t "yaml" sample # 파일 유형을 yaml 로 좁혀 sample 을 찾는다
```

```bash
app.yaml
9:       app: sample
14:           app: sample
```

`rg` 쪽이 빠르고 쓰기 쉬울 뿐 아니라 결과도 줄 번호 같은 맥락을 함께 담습니다.
