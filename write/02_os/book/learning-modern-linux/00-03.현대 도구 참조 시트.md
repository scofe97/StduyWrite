# 현대 도구 참조 시트

---

> 《Learning Modern Linux》 부록 B 의 현대 도구 표와 3장 끝에서 저자가 권하는 모던 대체를 모은 조회용 시트입니다.

## 이 문서의 성격

> 조회용 시트입니다. 학습 목표와 면접 질문은 두지 않습니다.

「본문」 열은 그 도구가 이어지는 본문 장입니다. "—"는 본문과 이어지지 않는 도구입니다.



## 1. 현대 도구 열넷

> 부록 B 의 표입니다. 라이선스와 대체 대상은 책이 나온 2022년 기준입니다.

3장은 자주 치는 명령으로 `cd`·`ls`·`find`·`cat`·`less` 다섯을 듭니다. 매일 수십 번 치는 명령이라 타건을 줄이려는 것이 모던 대체의 출발점입니다. 대체 도구는 합리적 기본값과 읽기 쉬운 출력을 주고 같은 일을 더 적게 쳐서 끝냅니다. `clear` 대신 Ctrl+L 을 누르라는 팁도 같은 취지입니다.

| 도구 | 라이선스 | 기능 | 대체·보완 대상 | 본문 |
|------|---------|------|---------------|------|
| `bat` | MIT · Apache 2.0 | 표시·페이징·구문 강조 | `cat` | 3장 끝 |
| `envsubst` | MIT | 템플릿 기반 환경 변수 | 해당 없음 | — |
| `exa` | MIT | 뜻이 있는 색 출력, 합리적 기본값 | `ls` | 3장 끝 |
| `dog` | European Union Public Licence v1.2 | 단순하고 강력한 DNS 조회 | `dig` | 7장(`dig`) |
| `fx` | MIT | JSON 처리 도구 | `jq` | — |
| `fzf` | MIT | 명령줄 퍼지 파인더 | `ls` + `find` + `grep` | — |
| `gping` | MIT | 다중 대상, 그래프 | `ping` | — |
| `httpie` | BSD 3-Clause | 단순한 사용자 경험 | `curl`. `curlie` 도 있습니다 | — |
| `jo` | GPL | JSON 생성 | 해당 없음 | — |
| `jq` | MIT | 네이티브 JSON 처리기 | `sed` · `awk` | 3장 끝 · 8장(`journalctl -o json`) |
| `rg` | MIT | 빠르고 합리적인 기본값 | `find` · `grep` | 3장 끝 |
| `sysz` | The Unlicense | `systemctl` 을 위한 `fzf` 인터페이스 | `systemctl` | 6장(`systemctl`) |
| `tldr` | CC-BY(내용) · MIT(스크립트) | 명령의 사용 예에 집중 | `man` | — |
| `zoxide` | MIT | 디렉터리를 빠르게 옮겨 다니기 | `cd` | — |

`exa` 의 저장소 [ogham/exa](https://github.com/ogham/exa) 는 2024년 9월 24일 뒤로 커밋이 없습니다. 포크인 [eza-community/eza](https://github.com/eza-community/eza) 는 2026년 8월에도 커밋이 이어집니다(2026-11-10 확인).

3장이 `exa`·`bat`·`jq` 를 권하는 이유입니다.

| 도구 | 권하는 이유 |
|------|------------|
| `exa` | Rust 로 쓰였고 Git 지원과 트리 렌더링이 들어 있습니다 |
| `bat` | 문법 강조와 페이저에 더해 출력되지 않는 문자 표시와 Git 지원을 갖췄습니다 |
| `jq` | `sed`·`awk` 대체라기보다 JSON 전용 도구입니다. HTTP API 와 설정 파일에서 자주 만납니다 |

저자는 이 도구들과 이해관계가 없고 유용해서 권한다고 밝힙니다. 기업 환경에서는 쓰는 배포판이 검증한 버전을 설치하라고 덧붙입니다.

`find` 와 `grep` 조합을 `rg` 하나로 줄인 예입니다. 출력은 저자의 것입니다.

```bash
find . -type f -name "*.yaml" -exec grep "sample" '{}' \; -print # *.yaml 마다 grep 을 돌려 찾으면 파일 이름을 찍는다
```

```bash
      app: sample
        app: sample
./app.yaml
```

```bash
rg -t "yaml" sample # 파일 유형을 yaml 로 좁혀 sample 을 찾는다
```

```bash
app.yaml
9:       app: sample
14:           app: sample
```

`rg` 는 더 빠르고 짧으며 줄 번호 같은 맥락을 함께 찍습니다.
