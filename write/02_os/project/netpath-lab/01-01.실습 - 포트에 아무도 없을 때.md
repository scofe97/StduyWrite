# 실습 - 포트에 아무도 없을 때

---

> 아무도 듣지 않는 포트에 요청을 보내 `tcp_refused` 를 만들고, 그 출력이 나온 코드를 되짚은 기록입니다. 지금은 Phase 3 막바지이고 열린 물음이 하나 남았습니다.

## 거절과 도달 불가는 다른 실패입니다

> 같은 "연결 실패" 인데 목적지까지 갔느냐에 따라 이름과 걸리는 시간이 갈립니다.

포트 9 는 discard 포트라 아무 프로세스도 듣지 않습니다. 그래서 여기에 요청을 보내면 커널이 RST 를 즉시 돌려줍니다.

```bash
./bin/netpath http://127.0.0.1:9          # TCP tcp_refused, 0.3ms
./bin/netpath --json http://localhost:9 | jq
./bin/netpath http://example.com:9        # TCP tcp_unreachable, 301ms
```

`127.0.0.1:9` 는 DNS 와 HTTP 를 건너뛰고 TCP 만 `tcp_refused` 로 0.3ms 만에 실패합니다. 예측과 같았습니다.

`example.com:9` 는 `refused` 가 아니라 `tcp_unreachable` 이었고 301ms 가 걸렸습니다. refused 는 목적지까지 가서 거절당한 경우입니다. unreachable 은 그리로 가는 길이 없다는 답을 받은 경우입니다. 에러 메시지는 `no route to host` 였고 대상은 IPv6 주소였습니다.



## DNS 를 건너뛰는 판단은 표준 라이브러리가 합니다

> netpath 에는 "이게 IP 인가" 를 가리는 코드가 없습니다. 훅이 불렸는지만 봅니다.

`probe.go` 의 `assemble` 은 `span.started()` 가 거짓이면 그 단계를 `skipped` 로 적습니다. 시작 시각은 `trace.go` 의 `DNSStart` 훅이 찍습니다. 대상이 `127.0.0.1` 처럼 이미 IP 이면 Go 의 HTTP 클라이언트가 조회를 하지 않으므로 이 훅이 불리지 않습니다.

이름을 주면 달라집니다. `localhost:9` 에서는 DNS 가 `ok` 가 되고 주소가 `::1`·`127.0.0.1` 둘로 풀렸습니다.



## 시도 횟수는 TCP 만 셉니다

> DNS 조회 한 번이 주소 여러 개를 돌려주면, Go 는 그 주소들로 TCP 연결을 차례로 시도합니다.

`localhost:9` 는 DNS 조회가 한 번이고 TCP 시도가 두 번(`attempts: 2`)이었습니다. 두 주소 모두 포트 9 에 아무도 없어서 둘 다 거부됐습니다. `::1` 에 문제가 있어서가 아닙니다.

에러 메시지에는 마지막 시도(`127.0.0.1`)만 남습니다. `ConnectDone` 훅이 매번 결과를 덮어쓰기 때문입니다. 그래서 앞의 실패는 `attempts` 숫자로만 드러나고, `result.go` 가 이 필드에만 `omitempty` 를 붙이지 않은 이유도 여기에 있습니다.

`example.com` 이 돌려준 주소 네 개는 IPv4 둘과 IPv6 둘입니다. `2606:4700:...` 은 MAC 이 아니라 IPv6 주소입니다. MAC 은 같은 네트워크 안에서만 쓰는 주소라 DNS 가 돌려주지 않습니다.



## Go — named type 과 포인터 필드

> `type Stage string` 은 가독성보다 컴파일러의 차단 때문에 둡니다. 포인터 필드는 "없음" 을 JSON 에서 통째로 빼기 위해 둡니다.

일반 `string` 변수를 `Stage` 를 받는 함수에 넘기면 컴파일이 깨졌습니다.

```bash
cannot use raw (variable of type string) as Stage value in argument to show
```

`show(Stage(raw))` 처럼 호출하는 쪽에서 변환해야 들어갑니다. 함수 정의부에 `Stage(raw)` 를 쓰면 안 된다는 것도 실수로 확인했습니다. 정의부는 받을 타입을 적는 자리입니다. `Stage`·`StageStatus`·`ErrorKind` 가 모두 문자열인데도 따로 타입을 둔 것은 셋을 섞어 쓰는 실수를 컴파일 단계에서 막기 위해서입니다. Go 에는 enum 이 없어서 named type 과 const 묶음이 그 역할을 합니다.

`Result.DNS` 가 `*DNSInfo` 인 이유도 두 실행을 비교해 확인했습니다. `127.0.0.1` 에서는 JSON 에 `dns` 키가 없었고, `localhost` 에서는 있었습니다.

차이는 필드 타입에서 나옵니다. 값 타입이면 zero value 구조체가 들어가 `omitempty` 가 빼지 않지만, 포인터면 nil 이라 키가 통째로 빠집니다.



## 열린 물음

> 이 물음에 답하면 Phase 3 을 닫고 학습 문서(Phase 2)와 검증(Phase 4)으로 갑니다.

`example.com:9` 에서 주소는 네 개인데 TCP 시도는 세 번뿐이었습니다. 하나를 시도하지 않은 이유를 찾습니다. 단서는 둘입니다. 에러 메시지에 남은 주소가 IPv4 인지 IPv6 인지, 그리고 301ms 라는 시간이 우연인지입니다.
